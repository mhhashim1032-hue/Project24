What this tool checks

Inspect HTML source for missing, empty, duplicate or malformed canonical link declarations. Results are a preliminary QA aid. Verify important findings against your production website, crawler logs and server responses.

How to use it

  1. Export or copy the relevant source data.
  2. Paste it into the input field above.
  3. Run the analysis and review every flagged item.
  4. Save the output and repeat the check after changes.

Limitations: this browser utility analyzes only the data you provide. It does not guarantee search indexing, ranking, crawler behavior or server-side redirect correctness.
